# PopX React Assignment

A React.js application built as part of the PopX Intern/Fresher Qualifier Task.

## Features

* Welcome Page
* User Registration
* User Login
* Profile Page
* React Router Navigation
* Local Storage Authentication
* Responsive Mobile-Centered Layout
* Reusable Components

## Tech Stack

* React.js
* Vite
* React Router DOM
* CSS3

## Installation

```bash
git clone <repository-url>
cd popx-react-assignment
npm install
npm run dev
```

## Project Structure

```text
src/
├── components/
│   ├── Button.jsx
│   ├── InputField.jsx
│   └── MobileContainer.jsx
├── pages/
│   ├── Welcome.jsx
│   ├── Login.jsx
│   ├── Register.jsx
│   └── Profile.jsx
├── App.jsx
├── main.jsx
└── index.css
```

## Functionality

* Users can create an account.
* User information is stored in Local Storage.
* Registered users can log in using their credentials.
* Profile page displays stored user information.
* Navigation is handled using React Router.
